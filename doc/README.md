# 竞赛技术文档全集（Doc）

全国大学生嵌入式芯片与系统设计竞赛 2026 · FPGA 创新设计赛道 · **选题一：基于高云 FPGA 的实时姿态控制系统**（J280 姿态控制系统竞赛套件）的全套工程技术文档。

> **项目入口请先读 [`../AGENTS.md`](../AGENTS.md)** —— 它给出两个代码仓库的位置、构建与验证命令、当前状态与硬性约定。本目录只是文档库。

## 目录结构与分类标准

```
doc/
├── README.md              本文件，文档导航
├── human/                 【给人看】原理讲解、实操步骤、调参方法论
│   ├── J280套件外设接口Verilog设计与原理详解.md
│   ├── J280套件硬件实物检测与校准实操指南.md
│   ├── 旋转倒立摆仿真算法与实物调参全指南.md
│   └── 旋转倒立摆实物闭环控制调参全流程指南.md
└── agent/                 【给 agent 看】项目状态快照、审计结论、缺陷清单、踩坑记录
    ├── 选题一_RTL代码合规性检查报告.md      第五轮 · 当前权威状态
    ├── 选题一_RTL代码复检报告.md            第三轮 · 历史存档
    └── 踩坑记录.md                          已付出代价的教训，动手前必读
```

**分类依据**：

| | `human/` | `agent/` |
| :--- | :--- | :--- |
| 回答的问题 | 「这个原理是什么、我该怎么动手做」 | 「项目现在处于什么状态、还有什么没做、以前错过什么」 |
| 内容性质 | 教程、推导、操作规程、调参方法论 | 审计结论、实测数据、待办清单、决策记录、失败复盘 |
| 时效性 | 长期有效，随知识体系演进 | **强时效**，绑定具体 commit，过期即须重写 |
| 阅读方式 | 顺序精读 | 按需检索，先读结论表 |

> `agent/` 下的报告同时对人有用（它是最完整的状态记录），但**写作目标是让一个从未接触本项目的 agent 在十分钟内知道该做什么、不该做什么**。

## 📚 human/ —— 技术文档矩阵

### 1. 📘 [《旋转倒立摆仿真算法与实物调参全指南.md》](./human/旋转倒立摆仿真算法与实物调参全指南.md)
* **核心定位**：顶层理论架构、数学推导与全系统仿真基石
* **主要内容**：
  - 系统软硬件拓扑与微秒级双速率离散化模型（1ms 控制主频 vs 0.2ms RK4 微步）；
  - 非线性欧拉-拉格朗日动力学运动微分方程理论推导；
  - 核心控制算法：平滑自适应 Lyapunov 能量泵、5 阶 LQI 零静差自平衡、连续正弦轨迹跟踪；
  - 仿真全局参数配置字典（`simulation/config.py` 全物理量定义）；
  - FPGA 逐比特定点数流水线硬件仿真与代码自动生成工具链。

### 2. 📗 [《J280套件外设接口Verilog设计与原理详解.md》](./human/J280套件外设接口Verilog设计与原理详解.md)
* **核心定位**：专为零硬件基础开发者打造的外设底层物理原理与 Verilog 源码精析
* **主要内容**：
  - 直流有刷电机与 H 桥驱动芯片（TB6612FNG / A4950）原理，20kHz 超音频高频 PWM 选型依据，影子寄存器无毛刺技术，刹车与滑行机制；
  - 增量式光电正交编码器（AB 相）原理，4 倍频鉴相状态机，8 级硬件数字消抖低通滤波，1ms 定时 M 法测速与一阶 IIR 平滑滤波；
  - 摆杆角度传感器（12 位 SPI ADC / 磁编码器）工作原理，2.5MHz SPI 主机时序状态机，360° 全圆周解卷绕，垂直绝对零位硬件锁存；
  - Q12.16 定点数与实际物理量（rad, rad/s, V, PWM）量纲转换字典。

### 3. 📙 [《J280套件硬件实物检测与校准实操指南.md》](./human/J280套件硬件实物检测与校准实操指南.md)
* **核心定位**：实物套件拿到手后的第一现场开箱检测、电气量测、传感器相位核验与零点标定实操
* **主要内容**：
  - 机械底盘稳固性与轴承灵活性微摩擦自由摆动衰减体检；
  - 万用表测定电机电枢线圈直流电阻 $R_m$ 排查短路断路；
  - 外接直流可调电源低压点动测试电机转向与转动平稳度；
  - 示波器量测驱动板 20kHz PWM 波形与编码器 A/B 相正交 90° 相位差；
  - 手转转臂一整圈核验 4000 CPR 脉冲精度测试法（区分单倍频/双倍频/电磁干扰毛刺）；
  - 电机起动死区电压 $V_{dead}$ 与库仑摩擦临界值实测规程；
  - 摆杆绝对垂直倒立零点（$ADC_{zero}$）高精度铅垂标定与极性统一实操；
  - **第〇章「安全上电 SOP」**：五步上电顺序，agent 与人在下板前都必须遵循。

### 4. 📕 [《旋转倒立摆实物闭环控制调参全流程指南.md》](./human/旋转倒立摆实物闭环控制调参全流程指南.md)
* **核心定位**：闭环控制实战调参方法论、工程五步调参法与现场异常排查速查字典
* **主要内容**：
  - 调参安全作业防线与硬件级倾角跌落超限（$>45^\circ$）急停切断保护；
  - 黄金调参哲学：「分层解耦、先直立后定位、先比例后积分、先微动后大摆」；
  - 阶段一：纯直立自平衡调参（锁定位置环，专注调整 $q_\theta$ 与 $q_{d\theta}$）；
  - 阶段二：水平转臂位置环调参（引入 $q_\alpha$ 与 $q_{d\alpha}$，实现中心定位与防游走）；
  - 阶段三：LQI 积分环调参（引入 $q_{\alpha\_int}$ 与积分抗饱和限幅，彻底消除稳态死区静差）；
  - 阶段四：能量泵平滑起摆与倒立区无冲击自动捕获联调（调节起摆加速度与捕获窗口）；
  - 阶段五：动态正弦轨迹跟踪与抗推力扰动性能测试（拓展要求 2）；
  - 实物调参全故障排查与参数反推终极速查表（蜂鸣高频抖颤、低频摇摆晃荡、冲过头倒下、起摆无力等现场问题的参数级针对性调节方案）。

### ⚠️ 两个必须知道的目录约定

1. **RTL 仓库是嵌套的独立 git 仓库**，不是 submodule。文档仓库的 `.gitignore` 已排除它；
   强行 `git add` 会把它变成 gitlink（伪 submodule），克隆者只会得到空目录。
2. **EDA 工具无法在中文路径下运行**（目录名「赛道」）。Gowin 报 `SP0002 Corrupted project file`，
   ModelSim 报 sqlite `DATABASE ERROR` 却**返回退出码 0**。
   统一经 `furuta_lqr_ctrl\eda.ps1` 调用，它会自动维护一个 ASCII junction（`C:\fpga_build`）。
   详见 [`../AGENTS.md`](../AGENTS.md) §1.2 与 [`agent/踩坑记录.md`](./agent/踩坑记录.md) A9。

> ⚠️ `../simulation/src_verilog/` 是**历史副本**，不参与综合与验证，已与 RTL 主仓库漂移。任何修改都必须落在 RTL 主仓库，详见 [`../AGENTS.md`](../AGENTS.md) 的「单一事实来源」约定。
