## 一、调参前置安全防线与紧急制动机制

旋转倒立摆电机转速高、摆臂旋转惯量大。在首次上电或参数尚未收敛时，极易发生电机全速飞车或摆杆甩打。**必须在硬件与逻辑两端筑牢安全底线**：

```mermaid
flowchart LR
    S1[1. 物理安全防护<br/>清空桌面旋转半径，严禁近距离俯身] --> S2[2. 电气物理总开关<br/>手指不离 12V 动力电源开关]
    S2 --> S3[3. FPGA 硬件倾角跌落切断<br/>|theta| > 45° 强制清零 PWM]
```

1. **物理安全作业区**：
   - 确保以电机转轴为圆心、转臂加摆杆全长为半径的**圆周范围内（至少 40cm）绝对无障碍物、无杂乱导线、无手部探入**；
   - 底座必须用台钳或夹具固定，严防机身被反扭力带飞；
2. **电气急停**：手指随时准备切断 12V 动力电源开关；
3. **FPGA 硬件倾角跌落保护**：
   在 [`j280_hw_top.v`](../../furuta_lqr_ctrl/src/j280_hw_top.v) 中已植入硬件级保护：当摆角偏差 $|\theta_{err}| > 45^\circ$ 时，硬件自动瞬间关闭 PWM，严防摆杆跌落后电机依然疯狂打旋。

## 二、黄金调参哲学与多闭环解耦思路

倒立摆系统包含 4 个相互耦合的物理状态（转臂角位移 $\alpha$、转臂角速度 $\dot{\alpha}$、摆杆倾角 $\theta$、摆杆角速度 $\dot{\theta}$）加上 1 个积分状态 $\int\alpha$。
> [!CAUTION]
> **绝对禁忌**：千万不要一开始就盲目同时调节 5 个增益参数！多变量同时变动会导致问题无法归因，调试陷入无序玄学。

**分层解耦调试路线图**：
$$\text{摆杆直立环 (使之不倒)} \longrightarrow \text{转臂位置环 (使之不跑)} \longrightarrow \text{LQI 积分环 (使之精准)} \longrightarrow \text{能量起摆环 (使之自起)}$$

```text
调试顺序表：
1. 关掉位置环与积分环 (令 q_alpha = 0, q_alpha_int = 0) -> 调 q_theta, q_dtheta -> 目标: 原地倒立稳定 (允许漂移);
2. 引入转臂位置环 (令 q_alpha > 0, q_dalpha > 0) -> 调位置刚度 -> 目标: 原地中心点平衡不游荡;
3. 引入积分环 (令 q_alpha_int > 0) -> 调积分增益与限幅 -> 目标: 彻底消除摩擦死区，静差严格归零;
4. 开启平滑能量泵 -> 调 swing_acc_amp 与切入窗口 -> 目标: 从自然下垂一击必中甩上顶点并锁定。
```

## 三、阶段一：纯直立自平衡调参（摆杆自平衡直立环）

此阶段的核心目标是：**赋予倒立摆“立住不倒”的姿态刚度与阻尼，哪怕转臂缓慢游走也不用管**。

### 1. 参数重置
在 [`simulation/config.py`](file:///c:/Users/28399/Desktop/赛道/simulation/config.py) 中，暂时将转臂相关的权重设为 0：
```python
q_alpha = 0.0        # 暂时关闭转臂位置约束
q_dalpha = 0.0       # 暂时关闭转臂速度约束
q_alpha_int = 0.0    # 暂时关闭积分环
q_theta = 30.0       # 初始比例增益
q_dtheta = 3.0       # 初始阻尼增益
r_u = 0.5            # 控制能量权重保持默认
```
运行 `python -m simulation.fpga_fixed_point_guide` 重新生成定点参数并烧录。

### 2. 实物调试动作
1. 按下 `key_zero_calib` 确保垂直绝对零点已经准确标定；
2. 拨上 `sw_motor_en` 开启电机驱动；
3. 用手轻轻扶起摆杆到垂直向上位置（零位附近），手感体会电机动作：
   - **负反馈核验**：当摆杆稍向右倾，电机转臂必须**迅速向右追赶支撑**；当摆杆向左倾，转臂向左追赶。若电机往反方向躲避导致摆杆加速倒下，立即断电，说明极性反了！
4. **调节比例刚度 $q_\theta$（摆角权重）**：
   - 若 $q_\theta$ 太小（如 10~20）：转臂追赶无力，手一松摆杆慢吞吞倒下；
   - 逐步增加 $q_\theta$（20 $\to$ 40 $\to$ 60）：摆杆直立刚度逐渐增强，能够感受到手松开后摆杆能在空中短暂停留；
   - 若 $q_\theta$ 过大（如 > 90）：摆杆会剧烈高频狂抖并伴随电机的蜂鸣尖叫。此时应适度下调。
5. **调节微分阻尼 $q_{d\theta}$（角速度权重）**：
   - 增大 $q_{d\theta}$（从 2.0 $\to$ 4.0 $\to$ 6.0）：高频抖动会被如同机油粘滞般迅速吸收，手扶摆杆在垂直点松手，摆杆能够平稳、安静地自平衡立在空中，无剧烈蜂鸣！
   - *（此时由于未加位置约束，转臂可能会慢慢往某一个方向单向漂移，这完全属于正常现象）*。

## 四、阶段二：水平转臂位置环调参（定点定位与防游走）

在摆杆能立住的基础上，我们需要给转臂施加“弹簧拉力”，让其**回到指定的中心目标点（$0^\circ$）并不再漫游**。

### 1. 参数激活
在 `config.py` 中激活转臂状态权重：
```python
q_alpha = 8.0        # 开启转臂位置恢复刚度
q_dalpha = 2.5       # 开启转臂速度阻尼
```
运行工具生成新参数并下载。

### 2. 实物调试动作
1. 将摆杆扶立松手，观察转臂动态：
   - 转臂如果偏离了中心位置，控制器应能在保持摆杆不倒的同时，带动转臂慢慢向原点靠拢；
2. **调节转臂位置刚度 $q_\alpha$**：
   - 若 $q_\alpha$ 偏小（如 3.0）：转臂回拉速度极慢，受轻微干扰后容易游荡到限位边界；
   - 逐步加大 $q_\alpha$（从 8.0 $\to$ 12.0 $\to$ 15.0）：转臂定点刚性显著增强，被推离原点后能强力拉回；
   - 若 $q_\alpha$ 过大（如 > 25.0）：位置环反客为主，转臂急躁回位导致摆杆失衡倒伏！
   > [!TIP]
   > **比例配比法则**：始终保持 $q_\theta$ 显著大于 $q_\alpha$（通常维持 $q_\theta : q_\alpha \approx 4:1 \sim 6:1$）。必须始终以“保摆杆不倒”为第一铁律！
3. **调节转臂速度阻尼 $q_{d\alpha}$**：
   - 适当增加 $q_{d\alpha}$（从 2.0 $\to$ 3.5）：消除转臂在原点附近缓慢左右游荡（低频晃荡现象），使转臂干脆利落地停在原点。

## 五、阶段三：LQI 积分环调参（克服摩擦死区消除静差）

### 1. 为什么必须加积分环？
实物电机齿轮箱和轴承存在约 $0.2\,\text{V} \sim 0.35\,\text{V}$ 的静摩擦死区电压。当转臂回位到距离目标仅剩 $1^\circ \sim 2^\circ$ 时，纯比例项计算出的修正电压已经小于死区阈值，电机停止出力，导致转臂永远残留微小的稳态静差。

### 2. LQI 积分参数配置
```python
q_alpha_int = 2.0         # 积分项状态惩罚权重
alpha_int_limit = 0.25    # 积分抗饱和限幅 (约 14.3 度)
```
### 3. 实物调试动作
1. 观察静差消除速度：
   - 给转臂施加一个轻微的外力扰动（用手指轻轻拨动转臂推离原点约 $15^\circ$ 后松手）；
   - 转臂在比例环作用下先快速回到 $1^\circ$ 附近，随后积分器持续蓄力微调，在 **0.5 ~ 1.0 秒内将转臂残余误差严格驱动至 0.0°**；
2. **防积分饱和调试**：
   - 若发现转臂在长距离回位时发生明显**超调冲过头**，说明积分饱和了。此时应减小 `alpha_int_limit`（例如从 0.25 降至 0.18）；
   - 在 [`j280_hw_top.v`](../../furuta_lqr_ctrl/src/j280_hw_top.v) 中已设置积分分离区间：仅当 $|\theta_{err}| < 22^\circ$ 平衡稳定区时才开启积分累加。

## 六、阶段四：能量泵平滑起摆与倒立区自动捕获联调

完成平衡调参后，系统已经具备极强的空中抓摆能力。现在调试**从静止下垂到自动甩起并捕获直立**（基础要求 1）。

```mermaid
flowchart TD
    HANG[自然悬垂状态: theta = 180°] -->|Lyapunov 能量泵| PUMP[转臂往复加减速，动能向势能传递]
    PUMP --> REACH{是否进入捕获窗口?<br/>|theta| < 22° 且 |dtheta| < 4.0}
    REACH -- 否 --> PUMP
    REACH -- 是 --> CAPTURE[状态机瞬间切入 5阶 LQI 平衡模式]
    CAPTURE --> BAL[摆杆锁定直立，转臂回中归零]
```

### 1. 核心调节参数（在 `config.py` 中）
* `swing_acc_amp`：起摆最大加速度（默认 30.0 rad/s²）；
* `swing_ke`：能量泵能量差增益（默认 14.0）；
* `balance_angle_thresh`：倒立区捕获角度窗口（默认 22.0°）；
* `balance_omega_thresh`：倒立区捕获角速度门限（默认 4.0 rad/s）。

### 2. 实物调试动作
1. 让摆杆静止自然垂直下垂；
2. 开启起摆控制，观察摆动轨迹：
   - **现象 A：能量不足，晃荡几下上不去** $\longrightarrow$ 每次甩动最高点距离倒立顶点还差 $30^\circ$ 以上：
     - **对策**：逐步增加 `swing_acc_amp`（从 30 $\to$ 35 $\to$ 40）；
     - 检查 12V 供电电源电压是否被大电流拉低。
   - **现象 B：能量过猛，直接冲过头倒向另一侧** $\longrightarrow$ 摆杆掠过最高点时速度太快：
     - **对策**：略微减小 `swing_acc_amp` 或增大平滑饱和因子 `swing_gamma`；
     - 适度放宽 `balance_omega_thresh`（如由 4.0 调至 4.8 rad/s），使平衡控制器能更早提前介入抱死摆杆。
   - **完美起摆标准**：摆杆经历 2 ~ 3 次往复蓄力晃动后，第 3 次被轻柔推至顶点，在角速度几乎为零的瞬间被 LQI 控制器“凌空点穴”稳稳捕获，无剧烈冲击！

## 七、阶段五：动态正弦轨迹跟踪与抗扰达标测试（拓展要求）

### 1. 连续动态正弦轨迹跟踪（拓展要求 2）
* **控制目标**：让电机按照指定正弦曲线 $\alpha_{ref}(t) = A \sin(2\pi f t)$ 往复运动，同时动态保持摆杆始终不倒；
* **参数设定**：
  - 振幅 $A = 25.0^\circ$（约 $0.436\,\text{rad}$）；
  - 频率 $f = 0.20\,\text{Hz}$（周期 5 秒，往复摆动优雅平稳）；
* **调试重点**：
  - 必须引入目标速度前馈：$\dot{\alpha}_{ref} = 2\pi f A \cos(2\pi f t)$；
  - 转臂误差向量实时更新为 $\alpha_{err} = \alpha - \alpha_{ref}(t)$ 和 $\dot{\alpha}_{err} = \dot{\alpha} - \dot{\alpha}_{ref}(t)$；
  - 观察摆杆：在转臂加速变向时，摆杆会前倾一个微小的动态平衡角（抵消惯性力），属于正常物理现象，全过程摆角偏离应 $< 2.0^\circ$。

### 2. 外部推力扰动与鲁棒性测试（基础要求 3）
* **测试动作**：在摆杆稳定倒立时，用中性笔笔尖轻弹摆杆顶端（施加瞬态脉冲扰动）；
* **达标表现**：摆杆瞬间偏斜 $< 12^\circ$，转臂迅速横移追赶，在 **0.3 秒以内完全平息晃动**，重新平稳停在中心位置。

## 八、实物调参全故障排查与参数反推终极字典

| 现场典型异常现象 | 物理根因诊断 | 精确到参数的修改指令 |
| :--- | :--- | :--- |
| **异常 1：摆杆在垂直倒立点高频剧烈蜂鸣抖颤，转臂发热大** | 1. 摆角增益 $q_\theta$ 过大，系统相位裕度过小；<br/>2. 角速度差分估算引入了高频量化白噪声。 | 1. 调小 `q_theta`（如从 60 降至 45）；<br/>2. 调大角速度阻尼 `q_dtheta`（如从 6.0 增至 8.0）；<br/>3. 加强 `angle_sensor_reader.v` 中的数字低通滤波。 |
| **异常 2：系统发生低频大摆幅摇晃（类似钟摆左右晃动 1~2Hz），迟迟停不下来** | 1. 角速度阻尼严重不足（欠阻尼）；<br/>2. 转臂速度反馈项 $q_{d\alpha}$ 偏弱。 | 1. 大幅度增大 `q_dtheta`（从 6.0 提升到 9.0）；<br/>2. 适当增大 `q_dalpha`（从 3.0 提升到 4.5），抑制低频机械能量晃荡。 |
| **异常 3：摆杆倒立稳定，但转臂停稳后总是偏离中心 1°~3°，无法精准回 0** | 电机存在机械静摩擦和起动死区电压，比例项输出电压已低于电机克服摩擦的临界值。 | 1. 增大 LQI 积分权重 `q_alpha_int`（由 2.0 增至 3.5）；<br/>2. 检查 `alpha_int_limit` 是否过小（推荐设为 0.25 rad）。 |
| **异常 4：定点位移指令下达时，转臂过度加速冲过头，来回拉扯几次才停下** | 积分饱和（Integral Windup），大步长过渡过程中累积了过大的虚拟积分力矩。 | 1. 减小积分抗饱和上限 `alpha_int_limit`（由 0.25 降为 0.15）；<br/>2. 缩紧积分开启区间（例如仅当 $|\alpha_{err}| < 10^\circ$ 时才积分）。 |
| **异常 5：起摆甩动 4~5 次依然冲不上倒立区，摆幅达到最大后停滞** | 1. 起摆加速度 `swing_acc_amp` 偏小；<br/>2. 供电电源电流限流或线阻过大导致电机电压跌落。 | 1. 增大 `swing_acc_amp`（从 30 增加至 38）；<br/>2. 换用粗电源线直接连接 12V 锂电池或大功率开关电源。 |
| **异常 6：起摆能甩过最高点，但直接从另一侧掉落，完全不进入自平衡模式** | 摆杆穿过倒立顶点时的角速度 $|\dot{\theta}|$ 超过了设定的切入上限门限 `balance_omega_thresh`。 | 1. 适度放宽 `balance_omega_thresh`（由 4.0 调至 4.8 rad/s）；<br/>2. 适当调大 `swing_gamma`，使能量在接近顶点时更快平滑衰减。 |
| **异常 7：轻轻碰一下摆杆，系统立刻切断动力软绵绵倒下** | 跌落安全保护阈值设置过小，正常受扰动动态过程被误判为翻倒。 | 将 `j280_hw_top.v` 中的跌落保护阈值由 $30^\circ$ 放宽至 **$45^\circ$**。 |
